# 設定を変更する

**【karita】** 「設定」を開き、変更したい項目を選びます。

| 項目 | 使う場面 |
|---|---|
| アカウント | 同期に使っている Google アカウントの確認 |
| 図書館設定 | 利用する地区・図書館・常用館の変更 |
| 開くブラウザー（Windows） | 外部サイトを開くブラウザーの選択 |
| ブラウザープラグイン（Windows） | [拡張の導入・連携確認](../extensions/index.md) |
| テーマ | 表示テーマの変更 |

ブラウザーを変更した場合は、そのブラウザーにも拡張を入れ、送信を確認します。

同期、バックアップ、復元、初期化の違いは[データ管理のページ](data.md)にまとめています。
