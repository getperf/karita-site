# 本棚・レビューを使う

Windows・Android・iPhone で同じ操作です。

## 本を探す

**【karita】** 「本棚」を開き、書名・著者・ISBNで検索するか、［読みたい］［読んだ］で絞り込みます。

![本棚で本を探す](../img/guide/bookshelf.png){ width="360" }

## レビューを保存する

1. **【karita】** 対象の本の「読みたい」、「読んだ」を押して、詳細を開きます。
2. 本棚の状態を確認し、必要なら「読んだ」にします。
3. レーティングとレビューを入力し、［レビューを保存］を押します。
4. 一覧へ戻り、同じ本を開き直して保存内容を確認します。

![本の記録で評価とレビューを保存](../img/guide/review.png){ width="360" }
