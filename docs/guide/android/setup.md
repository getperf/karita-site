# Android のセットアップ

**クローズドテスト中・一般公開準備中です。** Windowsを使っていない方も参加できます。

## インストールする

現在はクローズドテストで配布しています。テスターの方は[専用ページの参加・インストール手順](../../closed-test.md)を確認してください。

## karita を始める {#start}

karitaを起動し、ご自身のGoogleアカウントでサインインします。

- **初めて使う場合**：［新しく始める］を選び、画面の案内に沿って図書館・常用館を登録します。
- **ほかの端末の記録を使う場合**：元の端末で同期を済ませ、同じGoogleアカウントで［合流する］を選びます。同期後、予約・本棚・図書館の記録を確認してください。

端末追加のために初期化やバックアップ復元は行いません。[同期・バックアップ・復元](../data.md)を参照してください。

## 操作を試す

まず、[スマートフォンでの操作](../smartphone.md)で、Androidでの本の共有やアプリの切り替えを確認します。

次に、Windows版の手順を参照しながら、[図書の予約](../windows/reservation.md)、[貸出し・返却の記録](../loans.md)、[本棚・レビュー](../bookshelf.md)の基本操作を試します。Androidで予約するときは、スマートフォン向けガイドの順序に沿って操作してください。

テスト期間や感想の送り方は[クローズドテスト専用ページ](../../closed-test.md)をご覧ください。
