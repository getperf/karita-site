# 図書を予約する（Android）

!!! note "ドラフト・共有操作の実機確認待ち"
    Android の共有先の表示名・アプリへの戻り方・画像は確認後に確定します。

<div class="karita-flow" aria-label="Android 予約の流れ">
<div><b>karita → ブラウザー：カーリル</b><br>本を探す</div><span>↓</span>
<div><b>ブラウザー：図書館サイト</b><br>予約を完了する</div><span>↓ カーリルの本の詳細へ戻る</span>
<div><b>ブラウザーの共有 → karita</b><br>本を送る</div><span>↓</span>
<div><b>karita</b><br>本・図書館を確認し［予約した］</div>
</div>

1. **【karita】** 「予約」から［カーリルで探す］を開きます。
2. **【ブラウザー：カーリル】** 本を検索し、利用する図書館の予約へのリンクから進みます。本の詳細タブは残します。
3. **【ブラウザー：図書館サイト】** ログインして予約を確定し、完了を確認します。
4. **【ブラウザー：カーリル】** 元の本の詳細に戻り、ブラウザーの共有から karita を選びます。
5. **【karita】** 本・図書館を確認し、［予約した］を押します。「貸出し」の［予約中］に表示されれば完了です。

Windows の拡張ボタンに相当する箇所が、Android ではブラウザーの共有操作になります。
