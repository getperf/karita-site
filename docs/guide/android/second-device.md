# Android を2台目として追加する

**ゴール：Windows の記録を Android で開き、両方で変更を共有できる状態にします。**

<div class="karita-flow" aria-label="Android 追加の流れ">
<div><b>Windows の karita</b><br>同期完了・アカウントを確認</div><span>↓</span>
<div><b>Android</b><br>インストール・同じ Google アカウントでサインイン</div><span>↓</span>
<div><b>Android の karita</b><br>［合流する］→ 同期を待つ</div><span>↓</span>
<div><b>両端末の karita</b><br>既存の記録と変更の反映を確認</div>
</div>

クローズドテストでインストールする方は、先に[テスト参加・インストール手順](../../closed-test.md)をご確認ください。このページでは、Windowsの記録をAndroidでも使う手順を説明します。

## 1. Windows の記録を同期する

**【Windows の karita】** 設定で使用中の Google アカウントと同期状態を確認し、変更の送信が完了してから進みます。

## 2. Android で始める

1. **【Android】** 配布案内に従って karita をインストールし、起動します。
2. **【Android の認証画面】** Windows と同じ Google アカウントでサインインします。
3. **【karita】** 「今の記録に合流する（おすすめ）」の［合流する］を選び、同期を待ちます。

**2台目は今の記録へ合流します。** 旧版では［新しく始める］と表示される場合があります。バックアップ復元は不要です。操作の違いは[同期・バックアップ・復元](../data.md)を参照してください。

## 3. 両端末で確かめる

1. **【Android の karita】** Windows にある予約、本棚、図書館の記録を確認します。
2. レビューなどを1件変更して保存し、同期を待ちます。
3. **【Windows の karita】** 同じ本で変更が反映されたことを確認します。
4. Windows でその記録を変更し、Android にも反映されることを確認します。

[記録が出ない・変更が反映されないとき](../troubleshooting.md#sync)
