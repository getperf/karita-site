# Windows のセットアップ

!!! note "ドラフト"
    正式な入手先を掲載しています。ストアからの新規導入・認証・拡張連携の通し確認は実機検証予定です。

**ゴール：図書館を登録し、ブラウザーから karita に情報を送れる状態にします。**

1. インストールする
2. Google にサインインする
3. 開始方法を選ぶ
4. ブラウザーとつなぐ
5. 図書館を登録する

記録の同期とバックアップに使う **Google アカウント**を用意してください。

## 1. インストールする

1. **【ブラウザー】** [Microsoft Store の karita](https://apps.microsoft.com/detail/9P4DVHV81JSP?hl=ja-JP&gl=JP) を開きます。
2. 製品名が **karita**、発行元が **Getperf** であることを確認し、ページの案内に従って Microsoft Store からインストールします。
3. **【Windows】** インストール後、karita を起動します。

製品ページを開けない場合は、Windows の Microsoft Store で「karita」を検索してください。製品 ID は `9P4DVHV81JSP` です。

## 2. Google にサインインする

1. **【karita】** ［サインイン］を押します。
2. **【ブラウザー：Google】** 使用するアカウントを選び、表示されるアクセス内容を確認して進めます。
3. **【karita】** アプリへ戻り、開始方法の画面が表示されることを確認します。

Google の画面は、以前の同意状況により異なります。

## 3. 開始方法を選ぶ

**【karita】** 初めて使う場合は［新しく始める］、既存の記録を取り込む場合は［合流する］を選びます。

［バックアップから復旧する］は過去の記録へ戻す場合に使います。端末追加には不要です。詳しくは[同期・バックアップ・復元](../data.md)を参照してください。

## 4. ブラウザーとつなぐ

1. **【karita】** ［入れ方を開く］を押し、[拡張の入れ方](../../extensions/index.md)に従ってインストール・設定します。
2. **【karita】** ［確認ページを開く］を押し、ブラウザーで[連携を確認](../../extensions/check.md)します。
3. **【karita】** 「つながりました」と表示されたら［次へ］を押します。

## 5. 図書館を登録する

**【karita】** 地区 → 図書館 → 常用館を選び、保存します。利用する地区について繰り返し、［完了］で終了します。

［完了］を押して通常の画面に進めばセットアップ完了です。続けて予約する場合は、図書館の利用者番号・パスワードを用意してください。
