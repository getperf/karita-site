## 本体の導入・認証 {#setup}

### Microsoft Store の製品ページを開けない

Windows の Microsoft Store を起動して「karita」を検索します。製品名が **karita**、発行元が **Getperf** であることを確認してください。製品 ID は `9P4DVHV81JSP` です。

[Windows のセットアップへ戻る](windows/setup.md#1)

### Google の認証後に進まない

karita の画面へ戻って状態を確認します。エラーがある場合は、通信状態と、サインインに使った Google アカウントを確認してください。解決しない場合は[エラー文と環境を控えてください](#support)。

[サインインの手順へ戻る](windows/setup.md#2-google)

## 拡張の導入・連携 {#extensions}

### 「お使いのブラウザーと互換性がありません」と出る

Edge アドオンを Chrome で開くなど、掲載先とブラウザーが合っていない可能性があります。拡張を入れるブラウザーを起動し、[そのブラウザー用の URL](../extensions/index.md#1) をコピーしてアドレスバーへ貼り付けて開きます。

### ストアで拡張を追加できない

対象ブラウザーで対応するストアを開いているか確認してください。Firefox は142以降が対象です。組織の管理設定により追加が制限されている場合は、管理者へ確認してください。

### 拡張のボタンがない

拡張が追加されているかブラウザーの拡張機能メニューで確認し、[ツールバーへ固定](../extensions/index.md#2)します。ほかのブラウザーで送りたい場合は、そのブラウザーにも拡張を入れてください。

### 押しても karita が開かない・「つながりました」が出ない

1. 同じ Windows 端末に karita がインストールされているか確認します。
2. ストアやブラウザーの設定画面ではなく、[連携確認ページ](../extensions/check.md)を対象ブラウザーで開いて試します。
3. 外部アプリを開く確認が出たら、karita を開く操作を許可します。
4. 開かない場合は、拡張のポップアップの［ここから karita を開く］を試します。

「Web ページのタブで押してください」と出た場合も、連携確認ページなど普通の Web ページのタブで試してください。

### 拡張が使えないまま記録したい

karita の予約画面で URL を貼り付けたり、手で入力したりして記録できます。初回セットアップでは［プラグインなしで進む］から[図書館登録](windows/libraries.md)へ進めます。

[拡張の入れ方へ戻る](../extensions/index.md) ／ [連携確認へ戻る](../extensions/check.md)

## 本の受け渡し {#book-handoff}

### 元のカーリル書籍を選べない・送れない

予約の前に開いた **カーリルの本の詳細タブ**へ戻り、そこから送ります。検索結果や図書館の予約完了ページではなく、本の詳細ページを送ってください。

図書館タブから元の本を送るときにカーリルの読み取り許可を求められた場合は、[初回の権限許可](../extensions/check.md)を確認してください。

### 違う本が表示された

確定せずキャンセルし、正しい本の詳細ページから送り直してください。

[Windows の予約手順へ戻る](windows/reservation.md) ／ [Android の予約手順へ戻る](android/reservation.md)

## 同期・端末追加 {#sync}

### 2台目に記録が出ない・変更が反映されない

1. 両端末が同じ Google アカウントでサインインしているか確認します。
2. 通信状態と、karita の設定の同期状態を確認します。
3. 同期の完了を待ち、記録と変更の反映を確認します。

同じ本や図書館を登録し直す前に、上記を確認してください。端末追加の対処として初期化・バックアップ復元を実行しないでください。記録や他端末へ影響する操作です。

[同期・バックアップ・復元へ戻る](data.md) ／ [Android の端末追加へ戻る](android/second-device.md#3)

## 図書館の記録との照合 {#records}

### 図書館サイトの状態・期限と一致しない

karita は予約・貸出しの状態や期限を自動取得しません。[貸出しの棚卸](loans.md)で図書館サイトの実際の状態と照合し、karita の記録を手動で更新してください。

### 図書館サイトから貸出し画面へ戻れない

拡張に［貸出し画面（図書館別）に移動］が表示されない場合は、Windows の Alt＋Tab で karita に切り替え、確認していた図書館の貸出し画面を開きます。

[貸出しの棚卸へ戻る](loans.md)

## 解決しない場合 {#support}

アプリの版、OS、ブラウザーとその版、操作した場所、エラー文を控えてください。画面を共有する場合は、メールアドレス・利用者番号・氏名・認証情報を隠してください。
