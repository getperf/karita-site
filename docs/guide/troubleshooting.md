# 困ったとき

| 状況 | 確認すること |
|---|---|
| Google の認証後に進まない | karita に戻って状態を確認する。エラーがあれば通信と選択したアカウントを確認する |
| Windows の拡張で送れない | [拡張の対処方法](../extensions/index.md#trouble)へ |
| 元のカーリル書籍を送れない | カーリルの本の詳細タブへ戻り、そこから送る |
| 違う本が表示された | 確定せずキャンセルし、正しい本の詳細から送り直す |
| 拡張が使えない | karita の予約画面で URL 貼り付け・手動入力を使う |
| 2台目に記録が出ない | 両端末の Google アカウントと[同期状態](data.md)を確認する |
| 図書館の状態と一致しない | [貸出しの棚卸](loans.md)で、図書館サイトと照合して更新する |

解決しない場合は、アプリの版、OS、ブラウザー、操作した場所、エラー文を控えてください。画面を共有する場合は、メールアドレス・利用者番号・氏名・認証情報を隠してください。
