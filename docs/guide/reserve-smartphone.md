# 図書を予約する（Android・iPhone）

**ゴール：図書館で予約を済ませ、同じ本を karita に「予約した」と記録します。**

スマートフォンにはブラウザー拡張がないため、**先に本を karita へ送り、karita から図書館サイトを開いて予約します。** Windows とは順序が異なります。Windows は[図書を予約する（Windows）](reserve-windows.md)を参照してください。

<div><b>② カーリル</b><br>本を検索して、本の詳細ページを開く</div><span>↓ 共有で karita へ</span>
<div><b>③ karita</b><br>届いた本を確認し、予約する図書館を選ぶ</div><span>↓ ［この本を○○の図書館で開く］</span>

先に、共有メニューに karita を出す設定を済ませてください：[Android](../setup/android.md#share) ／ [iPhone](../setup/iphone.md#share)

## 1. 本を探す

**【karita → ブラウザー】** 「予約」画面で［カーリルで探す］を押します。**【カーリル】** 借りたい本を検索し、本の詳細ページを開きます。

## 2. 本を karita に送る {#send-book}

**【ブラウザー → karita】** 本の詳細ページを表示したまま、ブラウザーの共有から karita を選びます。

=== "Android（Chrome）"

    ［︙］→［共有］を押し、共有画面のアプリの列から karita を選びます。固定していれば、上段に並びます。Chrome の共有画面が先に開いた場合は、［… もっと見る］から選びます。

=== "iPhone（Safari）"

    共有ボタンを押し、アプリの列の karita を選びます。

=== "iPhone（Chrome）"

    アドレスバー右端の共有ボタンを押し、アプリの列の karita を選びます。ページが表示されるまで待ってから共有してください。新しいタブなどで Chrome 自体を共有しても、本は届きません。

karita の「予約」画面に「本が届きました」と表示されます。共有できないときは、本の詳細ページの URL をコピーし、karita の予約画面へ貼り付けられます。

## 3. 予約する図書館を選ぶ

**【karita】** 届いた本を確認し、「受取システム館」から予約する図書館を選びます。図書館の確認画面に、その図書館の蔵書が表示されます。

## 4. 図書館で予約を完了する

**【karita → 図書館サイト】** ［この本を○○の図書館で開く］を押します。本のページが分からない場合は［○○の図書館サイトを開く］から探します。

**【図書館サイト】** 利用者番号などでログインし、案内に従って予約を確定します。**予約が完了したことを確認してから、次へ進みます。** 画面や操作は図書館によって異なります。

## 5. 予約したことを記録する

**【図書館サイト → karita】** 端末のアプリ切り替えで karita に戻ります。図書館の確認画面の左上の ← で予約画面へ戻り、本と図書館を確認して［予約した］を押します。

「貸出し」の［予約中］で、対象の本と図書館が見つかれば完了です。次の本も、手順1〜5を繰り返します。
