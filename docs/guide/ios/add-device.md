# iPhone のセットアップ

**TestFlightでのテスト配布を準備中です。App Storeでの一般公開も準備中です。**

## TestFlight からインストールする

誰でも参加できるTestFlightの公開リンクを準備しています。準備ができ次第、このページに掲載します。

公開後は、iPhoneに[TestFlight](https://apps.apple.com/jp/app/testflight/id899247664)をインストールし、公開リンクからkaritaのテストに参加してください。

以下はインストール後の手順です。

## karita を始める

karitaを起動し、ご自身のGoogleアカウントでサインインします。

- **初めて使う場合**：［新しく始める］を選び、画面の案内に沿って図書館・常用館を登録します。
- **ほかの端末の記録を使う場合**：元の端末で同期を済ませ、同じGoogleアカウントで［合流する］を選びます。同期後、既存の記録を確認してください。

端末追加のために初期化やバックアップ復元は行いません。[同期・バックアップ・復元](../data.md)を参照してください。

## 共有メニューに karita を出す {#share}

SafariやChromeでカーリルの本の詳細ページを開き、共有メニューを開きます。

1. アプリの列を右端まで送り、［その他］→［編集］を押します。
2. 「候補」のkaritaの［＋］を押し、「よく使う項目」に追加します。
3. 並べ替えのつまみで上に移動し、［完了］を押します。

設定は端末ごとに一度行います。表示や並びはiOS・ブラウザーの版によって異なります。

[本を送って予約を記録する手順](../smartphone.md#iphone)を参照してください。
