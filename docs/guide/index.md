# karita の使い方

!!! note "ドラフト・実機で手順確認中"
    Windows の画面例をもとにしたガイドです。配布版での通し確認はこれから行います。

karita で記録を開き、ブラウザーで図書館の手続きを済ませ、karita に戻って記録します。

| 操作する場所 | ここで行うこと |
|---|---|
| **karita** | 図書館の設定、予約・貸出しの記録、本棚・レビューの管理 |
| **ブラウザー：カーリル** | 本を探し、所蔵する図書館を調べる |
| **ブラウザー：図書館サイト** | ログイン、実際の予約、貸出状況・期限の確認 |

**図書館での手続きと、karita への記録は別の操作です。** ブラウザーから送るだけでは、予約や貸出状況は自動更新されません。
