# 同期・バックアップ・復元

## 記録はどこにあるか

**この端末の記録 ⇄ Google Drive のアプリ専用領域 ⇄ 同じアカウントのほかの端末**

普段は端末内の記録を使い、Google Drive を介して変更を同期します。バックアップは、過去の時点へ戻すために別途保存するものです。

## 目的に合う操作を選ぶ

| したいこと | 操作 | 記録・ほかの端末への影響 |
|---|---|---|
| PCとスマホで最新の記録を使う | 同期 | 変更を端末間で共有する |
| Androidなど2台目を追加する | 同じ Google アカウントで［合流する］（旧版は［新しく始める］） | 既存の記録へ合流し、通常の同期で取り込む |
| 戻れる時点を保存する | バックアップ | 復旧用の記録を保存する。作成だけでは過去へ戻らない |
| 記録を過去へ戻す | バックアップから復元 | 選んだ時点を新しい正本にする。他端末は同期を停止し、同じデータへ合わせる操作が必要 |
| 記録を空にしてやり直す | 初期化 | この端末の本・貸出し・図書館の記録を消し、空の状態を新しい正本にする。他端末も同期を停止する |

!!! warning "復元・初期化は、端末追加のための操作ではありません"
    この端末だけを設定し直すつもりで実行しないでください。まだ同期していない変更が失われる場合があります。実行前に、確認画面で対象と影響を確認してください。

## 同期を確認する

**【karita】** 設定の同期状態を確認します。

[記録が出ない・変更が反映されないとき](troubleshooting.md#sync)を確認してください。
