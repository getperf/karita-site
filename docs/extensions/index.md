# ブラウザー拡張「karita に送る」の入れ方

カーリルや図書館のサイトから、本を karita（Windows）へ送るための拡張です。
Edge・Chrome・Firefox で使えます。

!!! note "暫定の入れ方です"
    拡張はまだ各ストアで公開していません。公開後は、ストアから入れる手順に差し替えます。

## 1. 入れる

=== "Edge / Chrome"

    1. [karita-send-0.5.1.zip](../downloads/karita-send-0.5.1.zip) をダウンロードし、**消さない場所**へ展開します（例: `ドキュメント\karita-send`）。
       展開したフォルダーを消すと、拡張も動かなくなります。
    2. アドレスバーに `edge://extensions`（Chrome は `chrome://extensions`）と入力して開きます。
    3. **開発者モード**をオンにします。
    4. ［展開して読み込み］（Chrome は［パッケージ化されていない拡張機能を読み込む］）を押し、手順1のフォルダー（`manifest.json` が入っているフォルダー）を選びます。

=== "Firefox"

    署名済みの配布ファイルを準備中です。用意でき次第、ここに掲載します。

## 2. ツールバーに出す（ピン留め）

入れた直後は、拡張のボタンがメニューの中に隠れています。

| ブラウザー | 操作 |
|---|---|
| Edge | ツールバーの **拡張機能**（パズルの形）→「karita に送る」の **目のアイコン** を押す |
| Chrome | ツールバーの **拡張機能**（パズルの形）→「karita に送る」の **ピン** を押す |
| Firefox | ツールバーの **拡張機能** →「karita に送る」の **歯車** →［ツールバーにピン留め］ |

ツールバーに karita のアイコンが出れば完了です。

## 3. 初めて送るとき

- **「karita を開きますか」と出たら［開く］**を押します。「常に許可」にチェックすると、次から出なくなります。
- 図書館のタブで **［カーリルタブの読み取りを許可］** が出たら、押して許可します。
  予約した本の元になったカーリルの書籍ページを見つけるためで、カーリル（`calil.jp`）以外のサイトは読みません。

## 4. つながったか確かめる

karita の「ブラウザーとつなぐ」から［確認用ページを開く］を押すか、
[確認用ページ](check.md) を開いて、ページの案内どおりに送ってください。
karita に「つながりました」と出れば完了です。

## うまくいかないとき {#trouble}

- **何も起きない**: karita が入っているか確かめてください。ポップアップの［ここから karita を開く］も試してください。
- **「Web ページのタブで押してください」と出る**: ブラウザーの設定画面や新しいタブでは送れません。確認用ページなど、普通のページのタブで押してください。
- **拡張のボタンが無い**: 手順2のピン留めを確かめてください。
- **ほかのブラウザーで送りたい**: そのブラウザーにも拡張を入れてください。拡張はブラウザーごとに入れます。

拡張が無くても、karita の予約画面で URL を貼り付けたり、手で入力したりして記録できます。
