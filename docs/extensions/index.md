# ブラウザー拡張「karita に送る」の入れ方

カーリルや図書館のサイトから、本の URL を同じ Windows 端末の karita へ送るための拡張です。
先に [Windows 版 karita](../guide/windows/setup.md) をインストールして起動してください。

## 1. ストアから入れる

使用するブラウザーで、そのブラウザー用の掲載ページを開いてください。
拡張はブラウザーごとにインストールします。ZIP の展開や開発者モードの設定は不要です。

!!! note "公開版の実機確認について"
    ストアからの新規導入・権限確認・karita への送信は、公開版を使って実機検証予定です。画面のボタン名や確認表示はブラウザーの版によって異なる場合があります。

=== "Edge"

    1. **Edge** で [Edge アドオンの「karita に送る」](https://microsoftedge.microsoft.com/addons/detail/hihnlcmokajbhleeediopaoflkllmgaa) を開きます。
    2. 名前が **karita に送る**、提供元が **Getperf** であることを確認します。
    3. ページのインストールボタンを押し、表示されるアクセス内容を確認して追加します。

=== "Chrome"

    1. **Chrome** で [Chrome ウェブストアの「karita に送る」](https://chromewebstore.google.com/detail/apkcdfgkmojfmgenockhgddmjcjpbphp) を開きます。
    2. 名前が **karita に送る** であることを確認します。
    3. ［Chrome に追加］を押し、表示されるアクセス内容を確認して追加します。

    2026年10月21日に公開版 0.6.1 の掲載を確認しました。

=== "Firefox"

    Firefox 142 以降が対象です。

    1. **Firefox** で [Firefox アドオンの「karita に送る」](https://addons.mozilla.org/ja/firefox/addon/karita-%E3%81%AB%E9%80%81%E3%82%8B/) を開きます。
    2. 名前が **karita に送る**、提供元が **Getperf** であることを確認します。
    3. ［Firefox へ追加］を押し、表示されるアクセス内容を確認して追加します。

## 2. ツールバーに出す（ピン留め）

入れた直後は、拡張のボタンがメニューの中に隠れている場合があります。

| ブラウザー | 操作 |
|---|---|
| Edge | ツールバーの **拡張機能**（パズルの形）→「karita に送る」をツールバーに表示する設定を選ぶ |
| Chrome | ツールバーの **拡張機能**（パズルの形）→「karita に送る」の **ピン** を押す |
| Firefox | ツールバーの **拡張機能**（パズルの形）→「karita に送る」の **歯車** →「ツールバーにピン留め」 |

ツールバーに karita のアイコンが出れば完了です。

## 3. 送って確かめる

karita のブラウザープラグインの案内から確認用ページを開くか、
[確認用ページ](check.md) を開いて、ページの案内どおりに送ってください。
外部アプリを開く確認が表示された場合は、karita を開く操作を許可します。
karita に **「つながりました」** と出れば完了です。

図書館のサイトで元のカーリル書籍を送る場合は、追加でカーリルの読み取り許可を求められることがあります。用途と操作は [確認用ページ](check.md) に記載しています。

## 開発版を使っていた方へ

Edge / Chrome で開発者モードから読み込んだ拡張がある場合は、ストア版とボタンを取り違えないよう、拡張機能の管理画面で開発版を無効にしてからストア版を追加し、連携を確認してください。
Firefox の旧自己配布版（.xpi を直接インストールしていた場合）からの移行は、いったん拡張を削除してからストア版を追加し、連携を確認してください。

## うまくいかないとき {#trouble}

- **ストアで追加できない**: 対象のブラウザーで掲載ページを開いているか確認してください。組織の管理設定により追加できない場合もあります。
- **何も起きない**: 同じ Windows 端末に karita が入っているか確かめてください。ポップアップの［ここから karita を開く］も試してください。
- **「Web ページのタブで押してください」と出る**: ストアやブラウザーの設定画面ではなく、確認用ページなど普通の Web ページで試してください。
- **拡張のボタンが無い**: 手順2のピン留めを確かめてください。
- **ほかのブラウザーで送りたい**: そのブラウザーにも拡張を入れてください。

拡張が無くても、karita の予約画面で URL を貼り付けたり、手で入力したりして記録できます。
図書館の予約・貸出しの状態や期限は自動取得されません。図書館サイトで確認し、karita の記録を手動で更新してください。
