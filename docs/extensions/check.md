# 連携の確認

このページを、ブラウザープラグイン「karita に送る」で karita へ送ります。

1. ツールバーの **karita のアイコン** を押します。

    !!! note "初めてのとき"
        「元のカーリルタブを読む権限がありません」と **［カーリルタブの読み取りを許可］** が出ます。
        押して、ブラウザーの確認で **［許可］** を選んでください。
        予約した本の元になったカーリルの書籍ページを見つけるためで、カーリル（`calil.jp`）以外のサイトは読みません。
        許可しなくても、このまま次へ進めます。

2. **［現在のページの URL を karita に送る］** を押します。
   「開いた元のタブが見つかりません」「カーリルの書籍ページではありません」などと出ても、そのまま進めて構いません。
3. 「karita を開きますか」と出たら **［開く］** を押します。
   「常に許可」にチェックすると、次から出なくなります。

karita の画面に **「つながりました」** と出れば完了です。

うまくいかないときは、[入れ方のページ](index.md#trouble) を見てください。
