# 連携の確認

このページを、ブラウザープラグイン「karita に送る」で karita へ送ります。

1. ツールバーの **karita のアイコン** を押します。このページは、押すとそのまま karita へ送られます。
2. 「karita を開きますか」と出たら **［開く］** を押します。
   「常に許可」にチェックすると、次から出なくなります。

karita の画面に **「つながりました」** と出れば完了です。

!!! note "図書館のサイトで初めて押したとき"
    「元のカーリルタブを読む権限がありません」と **［カーリルタブの読み取りを許可］** が出ます。
    押して、ブラウザーの確認で **［許可］** を選んでください。
    予約した本の元になったカーリルの書籍ページを見つけるためで、カーリル（`calil.jp`）以外のサイトは読みません。

うまくいかないときは、[困ったとき：拡張の導入・連携](../guide/troubleshooting.md#extensions)を確認してください。
