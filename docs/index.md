# karita

karita は、複数の図書館の予約・貸出し記録と読書履歴をまとめて管理するアプリです。

[▶ はじめに動画で使い方を見る](https://youtu.be/g-6wYKiPM6M){ .md-button .md-button--primary }

約3分10秒・無音・画面内字幕付き

## karita でできること

- 複数の図書館の予約・貸出し記録と返却期限を、まとめて確認できます。
- 読みたい本・読んだ本を本棚にまとめ、評価やレビューを残せます。
- Windows・Android・iOS の間で、記録を同期できます。

## カーリル・図書館サイトとの連携

![karita 図書の貸し出し管理の流れ。カーリルで本を探し、図書館サイトで手続きし、karita に記録をまとめます。](img/karita-library-flow.svg)

- カーリルで本や図書館の蔵書を探し、図書館サイトで予約などの手続きを行えます。
- Windows はブラウザー拡張「karita に送る」、Android・iOS はブラウザーの共有から、本の情報を karita へ渡せます。
- **図書館での手続きと、karitaへの記録は別の操作です。** 本を送るだけでは予約は完了しません。
- **予約・貸出しの状態や期限は自動更新されません。** 図書館サイトで確認した内容を、自分でkaritaに記録します。

記録の同期には利用者自身の Google Drive（アプリ専用領域）を使い、独自のサーバーは持ちません。
