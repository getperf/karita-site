## karita

karita は、複数の図書館の貸出し記録をまとめて管理するアプリです（Windows / Android 対応）。

1. Web ブラウザでカーリルのサイトから図書を検索し、図書館サイトで貸出しの手続きを行う
2. その結果を、ブラウザ拡張「karita に送る」で karita へ送る
3. karita がその貸出し記録を管理し、各図書館の予約状況・貸出し状況をまとめて確認できる
4. 読み終えた図書はレビューを記録し、読書履歴として管理する

書誌情報はカーリル・openBD へ端末から直接問い合わせ、蔵書データは利用者自身の Google Drive
（アプリ専用領域）を介して端末間で同期します。開発者独自のサーバーは持ちません。

ブラウザ拡張「karita に送る」（Chrome / Edge / Firefox）は、カーリルの書籍ページの URL を
karita アプリへ送るための小さな橋渡しです。
