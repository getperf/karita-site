## karita

karita は個人の蔵書・貸出し管理アプリです（Windows / Android）。書誌情報はカーリル・
openBD へ端末から直接問い合わせ、蔵書データは利用者自身の Google Drive
（アプリ専用領域）を介して端末間で同期します。開発者独自のサーバーは持ちません。

ブラウザ拡張「karita に送る」（Chrome / Edge）は、カーリルの書籍ページの URL を
karita アプリへ送るための小さな橋渡しです。
